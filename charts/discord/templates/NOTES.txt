Clan Europe Discord stack deployed!

  Release name: {{ .Release.Name }}
  Namespace:    {{ .Release.Namespace }}

Components:
{{- if .Values.bot.enabled }}
  - bot       (ghcr.io/clan-europe/bot)      — main Discord bot, port 3000
{{- end }}
{{- if .Values.event.enabled }}
  - event     (ghcr.io/clan-europe/event)    — event management bot, port 3000
{{- end }}
{{- if .Values.pocketbase.enabled }}
  - pocketbase (ghcr.io/clan-europe/pocketbase) — PocketBase backend, port 8090
{{- end }}

Quick access (port-forward):
{{- if .Values.pocketbase.enabled }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-pocketbase 8090:80
  # PocketBase admin UI: http://localhost:8090/_/
{{- end }}
{{- if .Values.bot.enabled }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-bot 3000:80
  # bot metrics: http://localhost:3000/api/metrics
{{- end }}
{{- if .Values.event.enabled }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-event 3001:80
  # event metrics: http://localhost:3001/api/metrics
{{- end }}

IMPORTANT:
  - Set DISCORD_TOKEN, POCKETBASE_PASSWORD, R2_ACCESS_KEY_ID, R2_ACCESS_KEY_SECRET
    via secrets.* values or provide a pre-created Secret with secrets.existingSecret.
  - Never commit real credentials to values files. Use sealed-secrets, external-secrets,
    or a values override file excluded from git.
  - bot.config.POCKETBASE_URL and event.config.POCKETBASE_URL should point to
    the in-cluster pocketbase service: http://{{ .Release.Name }}-pocketbase
